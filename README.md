Built by an AI agent for make.fun's "Sum up 21 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
python3 draw_n21.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`draw_n21.py` redraws `entry.png` deterministically (same bytes every run); `main.ts` (Node 22, standard library only) copies it to the output directory.
